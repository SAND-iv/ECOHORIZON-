Home Page

Technical Description

The Home Page serves as the central hub of the website. It was built using semantic HTML5 and styled with the global CSS file (`style.css`). The layout uses Flexbox for responsive card-based navigation to content pages. Interactive hover effects (scale and shadow transitions) were added to tiles using CSS. The page includes the website logo, mission statement, and links to all student content pages (`content_ST1.html` to `content_ST4.html`). The navigation bar is fixed at the top for consistent access.

Accessibility

All images have descriptive alt text. The card links are keyboard-navigable and include ARIA labels. Color contrast meets WCAG 2.1 AA standards.

Table Page

Technical Description

The Table Page features a responsive, themed table with 8 rows and 5 columns, including country flags, emissions data, renewable energy percentages, policy scores, and progress bars for 2030 targets. It uses rowspan/colspan for visual merging (progress bars) and CSS zebra striping for readability...

Accessibility

Table headers use `scope="col"`/`scope="row"`. All icons have ARIA labels, and the table includes a descriptive caption.

Content Page

Technical Description

The Content Page (`content_ST2.html`) includes internal anchor links for section navigation and a fixed "Go to Top" button (positioned with CSS). Layout uses Flexbox for responsiveness. Four themed images scale proportionally with percentage-based widths. Sections are divided with semantic `article` tags and hierarchical headings.

Accessibility

Images have alt text, and the "Go to Top" button is keyboard-focusable. Heading hierarchy ensures screen reader compatibility.

Challenges and Lessons Learned

  • Balancing global CSS with page-specific styles required careful specificity management.
  • Ensuring table responsiveness without horizontal scrolling was solved with `overflow-x: auto`.
  • Learned to optimize SVG icons for performance and accessibility.

Compliance

All pages validate without errors via W3C validators. Design follows WCAG 2.1 AA for contrast and keyboard navigation. Images are royalty-free with proper attribution. Complies with Janet regulations for ethical web practices.

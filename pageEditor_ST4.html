Profile Page

Description

The User Profile page presents a comprehensive personal dashboard with a circular profile photo, organized sections for skills with animated proficiency bars, volunteering history, personal interests, weekly availability calendar, and a functional contact form.

Technical Implementation

HTML Techniques

  • Semantic structure using <main>, <section>, <header>, <footer>
  • Profile section with semantic elements and containers
  • Form elements with various input types (text, email, tel, textarea)
  • Accessibility features with aria-label attributes
  • Skill bars using nested <div> elements
  • Table element for schedule display

CSS Techniques

  • Flexbox layout for centering content and responsive design
  • CSS transitions for hover effects
  • Animated skill bars with percentage indicators
  • Media queries for different screen sizes
  • Box shadows and border radius for visual effects
  • Custom styled form inputs and buttons

Key Features

  • Circular profile photo with hover animation
  • Animated skill proficiency bars
  • Responsive availability calendar table
  • Accessible contact form with validation
  • Complete keyboard navigation support
  • ARIA labels for screen reader compatibility

Sitemap Page

Description

This SVG-based sitemap provides a dynamic hierarchical diagram showcasing the complete website structure with color-coded nodes representing different page levels and interactive elements.

Technical Implementation

HTML Techniques

  • SVG implementation for interactive sitemap
  • Semantic structure using <main> and <section>
  • Accessibility with aria-label and role attributes
  • Interactive nodes as clickable <a> elements
  • Keyboard navigation with tabindex="0"

CSS Techniques

  • Custom styling for SVG elements
  • Color changes and scaling transformations on hover
  • Smooth transitions for interactive elements
  • Responsive SVG scaling with viewport
  • Drop-shadows and linear gradients applied to nodes

Key Features

  • Interactive SVG diagram with clickable nodes
  • Color-coded hierarchical structure
  • Smooth hover and focus transitions
  • Built-in navigation legend
  • Full keyboard accessibility
  • Responsive design for all screen sizes

Content Page

Description

This content-rich page offers an in-depth exploration of climate research and technological advancements, with internal navigation system, multimedia elements, and convenient "Back to Top" button.

Technical Implementation

HTML Techniques

  • Semantic structure with proper heading hierarchy
  • Internal navigation with anchor links
  • Multimedia with <img> and <video> elements
  • Alt text for images and proper heading structure
  • "Back to Top" button as fixed position anchor link

CSS Techniques

  • Flexbox layout for internal navigation menu
  • Hover effects for interactive elements
  • Box shadows and subtle borders for content sections
  • Smooth hover effects with transitions
  • Responsive media with max-width: 100%
  • Fixed positioning for "Back to Top" button

Key Features

  • Internal anchor navigation system
  • Responsive images and embedded videos
  • Fixed "Back to Top" button
  • Semantic section structure
  • Accessible content with alt text
  • Consistent styling with global CSS

Challenges and Lessons Learned

User Profile Page

Challenge: Creating responsive skill bars that accurately reflect percentages without JavaScript

Solution: Used nested <div> elements with percentage-based widths and CSS transitions

Lesson: Learned how to create visual data representations using pure CSS

Sitemap Page

Challenge: Making SVG fully accessible and keyboard-navigable

Solution: Added ARIA attributes, tabindex, and proper focus states

Lesson: SVG accessibility requires special attention to work with screen readers

Content Page

Challenge: Ensuring internal navigation works smoothly with long content

Solution: Used proper section IDs and tested across browsers

Lesson: Internal linking requires careful planning of document structure

Compliance

All pages comply with Janet web publishing regulations and WCAG 2.1 AA standards by:

  • Providing text alternatives for non-text content
  • Ensuring full keyboard accessibility
  • Maintaining sufficient color contrast
  • Using semantic HTML structure throughout
  • Including proper document titles and metadata
  • Making all forms accessible with proper labeling
  • Ensuring responsive design for all devices
  • W3C Validator has been used to validate all Sites SiteMap, Profile and Content Page

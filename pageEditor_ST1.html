Splash Screen

Technical Description

The Splash Screen was built using semantic HTML5 structure and styled via external CSS. A wrapper was used for centering content. It includes an icon logo, the site title, and a short mission. The background image uses CSS background-size: cover for full coverage. Flexbox ensures vertical and horizontal centering of content. The page includes a meta http-equiv="refresh" content="4; url=home.html" tag to redirect after 4 seconds. A CSS animated loader was created using @keyframes for visual feedback during the delay.

Accessibility

The Splash Screen uses semantic tags and high contrast text. The logo has descriptive alt text, and the heading hierarchy ensures screen readers interpret the content properly. A readable font and consistent color contrast support users with visual impairments

Volunteer Page

Technical Description

The Volunteer Page uses semantic HTML elements like main, section, and article to structure content. Cards are arranged with CSS Flexbox and CSS Grid for responsiveness. A dropdown filter (non-functional) was styled using select and hover effects. Each card features an image, text, and a hoverable button. The Ratings section uses review cards with placeholder # links and CSS effects like box-shadow and border-radius for visual enhancement. The feedback section includes a textarea and 5 clickable star icons for rating input, styled via Flexbox.

Accessibility

Images include alt text, buttons have descriptive aria-labels, and form elements use labels for screen reader compatibility. Reviews and feedback inputs are logically grouped and navigable via keyboard. The dropdown and form are both styled for focus visibility.

Content Page

Technical Description

The Content Page (content_ST1.html) includes internal anchor links that allow users to jump between sections easily. A side or top navigation list helps with quick access to different parts of the page. The layout is made responsive using Flexbox, and all images and videos adjust in size based on the screen width by using percentage-based scaling. Each section has a unique identifier, which allows smooth scrolling when a link to it is clicked. The "Go to Top" button is always visible while scrolling, achieved by fixing its position on the screen and setting a high layer order using CSS.

Accessibility

Every image has alt attributes and meaningful descriptions. Logical heading structure (e.g., h1 to h3) and Navigation is designed to be keyboard-friendly

Challenges and Lessons Learned

  • Implementing an animated splash screen with CSS loader was tricky—solved it using @keyframes and animation-delay.
  • Volunteer page layout using both Flexbox and Grid required careful nesting.
  • I learned to manage responsiveness using media queries and practiced clear structure via semantic HTML.
  • Validation helped clean up unclosed tags and minor structural issues early.

Compliance

All the pages I created follow the W3C standards and were successfully validated using the official HTML and CSS validators, showing no errors and only acceptable warnings. The design and content also meet the accessibility requirements outlined in the WCAG 2.1 AA guidelines, including proper use of color contrast, readable fonts, and support for keyboard navigation. In addition, I ensured that all images used are royalty-free and properly referenced. The website also aligns with Janet regulations by maintaining ethical, secure, and inclusive web practices, making the content accessible and safe for all users.
